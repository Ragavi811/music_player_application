My First Music Player

About

A simple music player developed using Python as one of my first-year engineering projects. This project was my introduction to programming and application development.

Features

- Play music
- Pause and resume playback
- Stop music

Technologies

- Python
- Pygame

Installation

Install the required library:

pip install pygame

How to Run

1. Install Python 3.
2. Install Pygame.
3. Open the Python file in an IDE.
4. Run the program and follow the available controls.

Learning Outcomes

- Practiced basic Python programming.
- Learned to use an IDE to run a program.
- Explored music playback using Pygame.
